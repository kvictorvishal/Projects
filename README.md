## Projects Overview

### 1️⃣ AI-Powered Question Answering System (RAG-Based)
**Domain:** Artificial Intelligence | NLP | Information Retrieval  

A document-based **Question Answering System** that allows users to upload documents and ask natural language questions about their content.

**Key Features:**
- Retrieval-Augmented Generation (RAG)
- FAISS-based vector similarity search
- OpenAI-powered language models
- FastAPI backend
- Streamlit frontend
- Dockerized deployment

📁 Folder: `AI-Powered Q&A System/`

---

### 2️⃣ Cash Flow Minimizer
**Domain:** Data Structures & Algorithms | Financial Optimization  

An optimized algorithmic solution that **minimizes the number of financial transactions** required to settle debts among a group of people.

**Key Features:**
- Greedy debt-matching algorithm
- Reduction of redundant transactions
- Implemented in **Python and C++**
- Time Complexity: **O(N²)**
- Suitable for expense-splitting and financial applications

📁 Folder: `Cash_Flow_Minimizer/`

---

### 3️⃣ Predictive AI Modeling for Diabetes Diagnosis
**Domain:** Machine Learning | Healthcare AI | Web Deployment  

An end-to-end **machine learning application** that predicts the likelihood of diabetes based on user health parameters.

**Key Features:**
- Data preprocessing and exploratory data analysis
- Machine learning model development using scikit-learn
- Model evaluation and performance analysis
- Flask-based web application
- Deployed on Heroku

📁 Folder: `Predictive AI Modeling for Diabetes Diagnosis/`
